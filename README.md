# 💛 给杨恬楸的告白网页

一个深蓝星空背景的浪漫告白网页：
- 精致发光「开启浪漫时刻」按钮
- 点击后播放背景音乐，中央绽放烟花（金/粉/玫红/淡紫）
- 浮现发光大字「杨恬楸 我喜欢你」
- 半透明信纸书信缓缓呈现

## 本地运行
直接双击打开 `index.html` 即可（须与本目录下的 `m-taku.mp3` 放一起，音乐才会播放）。

## 上传到 GitHub Pages 生成永久链接

1. 注册并登录 [GitHub](https://github.com)（免费）。
2. 点右上角 **➕ → New repository**，取一个名字（英文，如 `yq-by`），选 **Public**，**不要**勾选 "Add a README"，点 Create。
3. 进入仓库页面，选 **Add file → Upload files**。
4. 把本文件夹里的 `index.html` 和 `m-taku.mp3` **两个文件**一起拖进去，点 **Commit changes**。
5. 进入 **Settings → Pages**（左侧菜单）。
6. 在 **Branch** 下拉选择 `main`，文件夹选 `/ (root)`，点 **Save**。
7. 等 1~3 分钟，页面顶部会显示链接：`https://你的用户名.github.io/love-q-by-me`。
8. 把该链接发给对方/自己即可。

> 提示：若仓库名含大写或特殊字符，链接会自动转小写。也可以在 Pages 页面点击 **Visit site** 直接打开最终链接。

- `m-taku.mp3` —— 背景音乐（自动加载、循环播放）
